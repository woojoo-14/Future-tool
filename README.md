# 전역 후 진로 방향 잡기 도구 (웹앱)

`PRD_전역진로도구.md`를 바탕으로 만든 정적 웹앱입니다. 서버·로그인·AI 없이 브라우저에서만 동작하고, 입력 내용은 사용하는 기기의 브라우저(localStorage)에만 저장됩니다.

## 실행 방법

### 방법 1. 더블클릭 (가장 쉬움)
1. 이 폴더의 **`start.bat`** 을 더블클릭합니다.
2. 잠시 후 브라우저가 열리며 `http://127.0.0.1:8080` 으로 접속됩니다. (이 PC에서만 접속 가능)
3. 끝낼 때는 검은 창(터미널)을 닫으면 됩니다.

> Python이 설치되어 있으면 로컬 서버로 실행하고, 없으면 `webapp/index.html`을 브라우저로 바로 엽니다.

### 방법 2. 파일 직접 열기
`webapp/index.html` 을 더블클릭하면 브라우저에서 바로 열립니다. 서버가 필요 없습니다.

### 방법 3. 터미널에서 실행
```bash
cd webapp
python -m http.server 8080 --bind 127.0.0.1
```
브라우저에서 `http://127.0.0.1:8080` 을 엽니다.

## 사용 흐름
1. **시작 화면**: 대원/간부 선택, 전역일 입력
2. **질문 화면**: 6단계(학력·전공 → 복무 경험·자격 → 관심 분야·강점 → 가치·일하는 방식 → 학업·지역·준비 → 한 줄 메모)
3. **결과 화면**: 강점·경험 정리표(학력·전공 포함) / 진로 후보 3개와 이유 + 그 밖에 살펴볼 만한 진로 3개 / 기간별 할 일 / 면담 질문 3개
   - `인쇄 / PDF 저장` 버튼 → 인쇄 창에서 "PDF로 저장"을 선택하면 파일로 저장됩니다.
   - `기록 지우기` 로 저장된 내용을 삭제할 수 있습니다.

## 내용을 바꾸고 싶을 때
- 질문, 선택지, 점수(`w`), 이유 문장(`because`), 이력서용 문구(`phrase`) → `webapp/data.js`의 `QUESTIONS`
  - `because` 문장은 그 선택지가 해당 후보에 2점 이상을 줄 때만 이유로 쓰입니다.
- 진로 후보(21개) → `CANDIDATES`
  - `name`·`desc`: 이름과 설명, `fit`: 이유 마지막 문장, `starter`: 첫 단계 맞춤 할 일 2개, `ask`: 면담 질문, `track`: 할 일 유형
  - 후보를 추가하려면 `CANDIDATES`에 항목을 넣고, `QUESTIONS`의 선택지 `w`에 새 id로 점수를 주면 됩니다.
- 유형별 할 일과 면담 질문 → `TRACKS` (job 일반 취업 / exam 시험형 / skill 자격·훈련 / study 학업 / own 창업·프리랜서 / abroad 해외)
- 모든 후보 공통 할 일 → `COMMON_TASKS`
- 준비 정도·희망 지역에 따른 첫 구간 할 일 → `PREP_TASKS`, `REGION_TASKS`
- 간부 전용 할 일 → `OFFICER_TASK`, 2순위 할 일 문구 → `SECOND_TASK`
- 답변과 어긋나는 후보 제외 → `EXCLUDE_RULES`, 어긋나는 답변 조합 안내 → `CONFLICTS`

## 후보 선정 규칙
1. `EXCLUDE_RULES`에 걸리는 후보는 뺍니다. (예: 졸업자에게 복학, 학업 계획 없음에 편입)
2. 선택한 답변의 점수(`w`)를 후보별로 더합니다. (학과명 입력은 점수에 쓰지 않습니다)
3. 동점이면 근거 답변 수 → 가장 강한 근거 → 목록 순서로 정합니다. 1·2순위가 동점이면 화면에 안내합니다.
4. 결과 3개: 1순위 + 1순위와 **다른 분야**(IT·기술 취업 / 사무·서비스 취업 / 공공·공무원 / 자격증·학업 / 창업·프리랜서·기타) 중 최고 후보 + 남은 후보 중 최고. 표시는 점수 순입니다.
5. 그 밖에 살펴볼 만한 진로: 다음 순위 3개를 이름과 설명만 표시합니다.
6. 같은 근거 문장은 후보끼리 반복하지 않게 나눠 씁니다.

## 할 일 기간 나누기
오늘부터 전역일까지를 남은 일수에 따라 고르게 나눕니다. 30일 이하는 1구간, 60일 이하는 2구간, 그 이상은 3구간입니다.
